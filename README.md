# Qarz Nazorati

Хакатон **Moliyaviy savodxonlik** — контроль долговой нагрузки: все кредиты, микрозаймы и рассрочки на одном экране.

## Что умеет MVP

- Ввод дохода и обязательств
- Долговая нагрузка относительно 50% (рекомендация ЦБ)
- Симулятор «а если возьму ещё одну рассрочку?»
- План выхода (сначала долг с самым большим платежом)
- ИИ-пояснение цифр и разбор текста договора (ключ опционален)
- UZ / RU, гостевой режим (данные в браузере)

Расчёты делает код, ИИ только объясняет. Это не финансовая консультация.

## Запуск

```bash
npm install
npm test
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## ИИ (необязательно)

В `.env.local`:

```
GROQ_API_KEY=...
```

или `ANTHROPIC_API_KEY`. Без ключа показываются локальные пояснения.

## Firebase

Для облачного аккаунта добавьте проект Firebase (email + Google, Firestore: читать/писать только владелец). Пока вход работает локально.
